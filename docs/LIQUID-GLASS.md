# Liquid Glass

Компонент: `src/components/ui/liquid-glass-button.tsx`.
Пример: `/ui/button`, файлы `src/app/ui/button/page.tsx` и `src/components/ui/LiquidGlassButtonDemo.tsx`.

Это самостоятельная реализация по визуальному ориентиру пользователя, не копия закрытого исходника 21st.dev. Страница референса: https://preview.21st.dev/@jahed/components/apple-tahoe-liquid-glass-button . На ней доступен код демо; код самой кнопки предлагается после входа. Из демо не заимствованы внешние фоновые изображения или зависимость framer-motion.

## Использование

```tsx
"use client";

import { LiquidGlassButton } from "@/components/ui/liquid-glass-button";

export default function Example() {
  return (
    <LiquidGlassButton onClick={() => console.log("click")}>
      Выбрать бистро
    </LiquidGlassButton>
  );
}
```

- Обычные props нативного button: `onClick`, `type`, `disabled`, `aria-*`, `ref`, `className` и другие.
- `type="button"` по умолчанию, без случайной отправки форм.
- `appearance="light" | "dark"`: цвет текста и тонирование поверхности.
- `interactive`: блик от положения указателя, увеличение при наведении и сжатие при нажатии. По умолчанию `true`.
- `refraction`: сила SVG-преломления, по умолчанию 16.
- `blur`: размытие фона в пикселях, по умолчанию 2.
- Экспорт `LiquidGlass` — аналогичная поверхность для содержимого, с `interactive=false` по умолчанию и стандартными props div.

Стили — Tailwind. Inline custom properties нужны только для динамического идентификатора SVG-фильтра, размытия и координат блика. Надпись — оригинальный Tehnikum Light. Фильтр применяется к отдельному слою фона, не к тексту. Идентификаторы фильтров уникальны для каждого экземпляра.

Учтены disabled, клавиатурный фокус, reduced motion и отсутствие hover на телефоне. Если SVG-фильтры фона не поддерживаются, предусмотрен blur; без backdrop-filter — полупрозрачная поверхность. Точное изображение и работоспособность SVG backdrop-filter в разных браузерах ещё требуют визуальной проверки. Следование всей кнопки за курсором по экрану, как в исходном демо, не добавлено: здесь интерактивность локальна самой кнопке.

Демостраница показывает кнопку и поверхность на абстрактном фоне фирменных цветов. «Сменить фон» переключает светлую и тёмную сцены; основная кнопка ведёт на `/map`. В хедере остаётся принятая ранее текстовая ссылка.
