## Смысл бренда, который можно извлечь

По S7, главы 1–5:

- Суть: «Интересная гастрономия на каждый день без барьеров».
- Формат: демократичное городское гастробистро; понятная еда с оригинальными вкусовыми сочетаниями, коктейли, живая дружелюбная атмосфера без снобизма.
- Три результата для человека: вкусно есть, пробовать новое, чувствовать себя своим.
- Пять ценностей: демократичность, творческая простота, уважение ко времени, дружелюбие, современность.
- Ядро: мужчины и женщины 18–30 лет с активной городской жизнью; гости старше входят в расширенную аудиторию. Это ориентир коммуникации, не ограничение доступа.
- Пять сегментов: районные гости; любители новых вкусов; компании и пары; гости театров и прогулок; заказчики домой и на работу.
- Продуктовые сценарии: завтрак, обед, полдник, ужин, поздний ужин, доставка, сертификаты. Наличие сценария в платформе не подтверждает его доступность в каждой локации.

Следствие для будущего сайта — моя рекомендация: понятность выбора ресторана и предложения, короткие тексты, небольшое число шагов и ощущение открытости. Эти принципы ещё не задают конкретный макет, анимацию или набор функций.

## Как передавать контекст без домыслов

Полезно разделять каждое утверждение по пяти полям:

1. Значение: что именно известно.
2. Источник: ID, страница/глава/ветка.
3. Статус: утверждено по документу / рабочая версия / планируется / спорно / неизвестно.
4. Область: весь бренд, конкретный ресторан, конкретный канал.
5. Актуальность: версия, дата действия и необходимость перепроверки.

Например: `Средний чек = 1500 ₽; S7, глава 1 и примечание в конце; ориентир платформы; бренд; текущий фактический чек не подтверждён`. Или: `Сигма-бой; S7, открытые решения п. 2; планируется; меню; действующее наличие неизвестно`.

Это лучше, чем общее «ничего не придумывать». Для творческой разработки нужно разрешать новые предложения, но маркировать их как предложения. Факты о ресторане, готовые маркетинговые формулировки и проектные гипотезы должны различаться.
