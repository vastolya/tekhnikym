## Фирменный шрифт

По прямому указанию пользователя актуальный источник всех шрифтов — `D:\tekhnikym\fonts`. Файлы скопированы в `src/fonts`, идентичность проверена SHA-256:

- `Tehnikum Light.otf` → `Tehnikum-Light.otf`, Light 300, Tailwind `font-brand`.
- `Courier New.ttf` → `Courier-New.ttf`, Regular 400, Tailwind `font-brand-mono`.
- `Courier New Bold.ttf` → `Courier-New-Bold.ttf`, Bold 700, та же гарнитура.
- `Courier New Italic.ttf` → `Courier-New-Italic.ttf`, хранится как часть комплекта; в интерфейсе не подключён согласно ограничениям S2.

Первоначальная копия Tehnikum Light из архива меню заменена файлом из указанной папки. Подключение — `next/font/local`; автоматические Arial fallback и системные списки Courier/monospace убраны. Базовый текст — локальный Courier New, акцидентный набор — Tehnikum Light. Искусственное утолщение и наклон отключены через `font-synthesis: none`.
