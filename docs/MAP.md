По новому референсу пользователя (`Screenshot 2026-11-05 235932.png`) схема заменена подробной картой на весь экран:

- MapLibre GL JS 6.16.0, загружается клиентским ES-модулем с официального UNPKG CDN.
- Тёмная векторная подложка OpenFreeMap Dark: города, водоёмы, дороги и здания при приближении. Подложка отображается в оттенках серого, фирменные метки остаются красными.
- Оттенение рельефа Mapterhorn, Terrarium raster-dem 512 px. Источник не превращается в 3D: используется hillshade.
- Перемещение мышью/касанием, колесо, pinch-to-zoom, клавиатурная навигация движка, кнопки +/- и возврат к обзору.
- Список слева поверх карты, как в референсе; на телефоне панель снизу. Есть режим списка, который работает и при недоступной подложке.
- Все 10 записей исходной схемы сохранены. Группы городов — `src/data/map-cities.ts`.
- Фирменные SVG пяти городов используются поверх карты. Близкие города группируются в красный круг с количеством локаций; нажатие приближает группу. Счётчик включает сезонные/планируемые записи, а не обозначает число открытых бистро.
- Выбор города или записи списка приближает город и раскрывает имеющийся адрес. Ранее выбранная локация сохраняется, если выбор сделан до загрузки SDK.
- Движение меток синхронизировано нативным MapLibre Marker с `subpixelPositioning=true`. Компонент `NativeMapMarker.tsx` монтирует React-содержимое через portal, но координатами/transform внешней оболочки владеет движок. Не возвращать цепочку `move → requestAnimationFrame → setState → left/top`: она давала отставание от подложки. Перегруппировка выполняется только по `moveend` и `resize`, все восемь городов остаются в наборе, включая находящиеся за экраном. Координата кластера — `unproject` его центра, поэтому при движении она остаётся привязанной к географии. При удалении компонента Marker снимает свои подписки.
- Закрытие крестиком возвращает на главную. Хедер на полноэкранной странице карты не показывается.

## SDK, стили и шрифты

`public/scripts/maplibre-loader.js` импортирует закреплённую версию `https://unpkg.com/maplibre-gl@6.16.0/dist/maplibre-gl.mjs`. CSS той же версии подключён на странице карты: это служебные стили внешнего картографического движка. Собственные элементы интерфейса написаны на Tailwind.

CDN-подключение выбрано после ошибки EACCES при установке пакета в среде агента. Ручная установка не нужна для текущей реализации. Карту, SDK и рельеф браузер получает из интернета; серверная сборка их не скачивает. Для недоступной сети предусмотрены сообщение и повторная загрузка, без потери списка бистро.

`src/lib/maplibre-browser.ts` описывает используемую границу SDK и подготавливает стиль: удаляет внешние glyphs, переводит text-font на уже загруженный локальный Courier New и включает русское имя при его наличии. Остальные поля, например номера дорог, сохраняются. Интерфейс использует только Tehnikum Light и Courier New из пользовательского комплекта. Reduced motion отключает перелёты.

Источники интеграции:

- MapLibre, установка и CDN: https://maplibre.org/maplibre-gl-js/docs/
- Локальные шрифты MapLibre v6: https://maplibre.org/maplibre-gl-js/docs/examples/style-labels-with-local-fonts/
- OpenFreeMap: https://openfreemap.org/quick_start/ ; стиль https://tiles.openfreemap.org/styles/dark
- Mapterhorn: https://mapterhorn.com/data-access/ ; тайлы https://tiles.mapterhorn.com/{z}/{x}/{y}.webp

В интерфейсе сохранены ссылки атрибуции MapLibre, OpenFreeMap, OpenMapTiles, OpenStreetMap и Mapterhorn.

## Проверки и ограничения

Исправлен конфликт CSS внешнего SDK: его unlayered `.maplibregl-map { position: relative }` перекрывал Tailwind `absolute`, оставляя контейнер без заданной высоты. Теперь контейнер имеет `absolute! h-full w-full` и защищённую локальную гарнитуру `font-brand-mono!`. Размеры меток приведены к 64×48 без предупреждения Next Image.

- ESLint и production-сборка с TypeScript прошли.
- Проверены сохранение 10 локаций при раздельных/объединённых кластерах, пустой экранный набор, подстановка локального шрифта, добавление рельефа и отсутствие изменения исходного стиля.
- Dev `/map` возвращает HTTP 200; синтаксис загрузчика проверен Node.
- Установка npm и прямые внешние загрузки в среде агента ограничены. Реальная загрузка CDN, векторных/DEM-тайлов, WebGL, визуальный результат и жесты в браузере не проверены. Ранее попытка запуска Chrome была отклонена автоматической проверкой разрешений. HTTP 200 и успешная сборка не считаются подтверждением работы внешних картографических сервисов.
