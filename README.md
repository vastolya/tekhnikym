# Сайт сети бистро Техникум

Минимальный проект на Next.js 16 с App Router, TypeScript, Tailwind CSS 4 и ESLint.

## Запуск

Нужен Node.js 20.9 или новее и npm.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000.

В PowerShell с запретом выполнения скриптов используйте `npm.cmd` вместо `npm`.

## Команды

- `npm run dev` — сервер разработки.
- `npm run build` — production-сборка.
- `npm start` — запуск production-сборки.
- `npm run lint` — проверка ESLint.
- `npm run typecheck` — проверка типов.

## Файлы

- `src/app/page.tsx` — главная страница.
- `src/app/layout.tsx` — общий layout и метаданные.
- `src/app/globals.css` — глобальные стили.

Пока добавлена только стартовая страница. Дизайн и разделы будем делать отдельными задачами.
